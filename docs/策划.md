# 逻辑

## 搜索的逻辑（什么样的关键词搜出什么样的词？）

- 玩家从主页或搜索结果页的搜索框提交一个关键词后，跳转到搜索结果页；关键词通过 URL 参数传递。
- 搜索时去除关键词中的空白字符，并忽略英文字母大小写。
- 对每篇帖子，逐项检查 `meta.keywords`；关键词经同样处理后只要包含玩家输入的完整搜索词，该帖子即为匹配结果。搜索仅匹配 `meta.keywords`，不匹配标题、正文或回复中的其他文字。
- 搜索结果包含所有匹配帖子，包括 `meta["search-only"]` 为 `true` 的帖子。
- 搜索结果页顶部显示刚刚搜索的关键词，下面列出匹配帖子；没有匹配项时显示无结果提示。

## 匿名的逻辑

帖子有两种，匿名贴和非匿名贴。

匿名贴的发帖人和回复者根据该帖 `anonymousIdentities` 数组，按真实用户 ID 映射到匿名名称和对应头像；映射在每篇帖子中明确记录，不在加载时随机生成。

在玩家解锁该用户的匿名状态后，在所有的帖子里面，该用户的头像和昵称变回其原本的头像和昵称。

## .json帖子文件的格式

### posts:

帖子文件采用 `texts/posts/post-*.json` 格式，首页通过 `texts/posts/index.json` 中的文件名清单加载。

- `meta`：帖子元数据，包含 `board`（版块）、`isAnonymous`（是否匿名）、`pinned`（是否置顶）、`title`（标题）、`author_id`（真实楼主用户 ID）和 `keywords`（关键词数组）。
- `meta["search-only"]`：布尔值。`false` 表示在主页帖子列表中显示；`true` 表示从主页列表中隐藏，但仍可通过 `meta.keywords` 搜索到。新增帖子必须明确填写此字段。
- `content`：正文文本。
- `replies`：回复数组；每项包含 `authorId`（真实回复者用户 ID）和 `content`（回复文本），数组顺序即显示顺序。
- `anonymousIdentities`：长度为 6 的整数数组，下标 `0` 至 `5` 分别对应真实用户 ID `1` 至 `6`，值为 `configs/anonymous.json` 中对应匿名身份的 `id`。映射以帖子为单位，同一真实用户可在不同帖子中使用不同匿名身份。管理员用户 ID `0` 不在此映射中。

`author_id` 和 `authorId` 始终记录真实用户 ID。匿名展示只改变页面显示：未解锁时使用该帖映射的匿名身份，解锁后使用 `configs/users.json` 中的真实昵称和头像；不能为了匿名而改写作者 ID。非匿名帖直接显示真实身份。
