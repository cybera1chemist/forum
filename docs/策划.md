# 网页的结构

## 登录

要求输入账号密码。
玩家输入正确的账号密码后，提示说：登录成功，并显示头像和昵称
昵称写的是“【管理员】萌萌小兔兔宝宝”
显示“加载中……”，然后等待1秒后跳转到主页

## 导航栏

导航栏不是一个单独的页面，而是一个部件。除了登录页面等特殊页面外，其他页面都有一样的导航栏。
（它们还全都有一样的footer！但是footer没啥信息，就不单独写了）

导航栏最左侧是论坛的名字（暂时没想好叫什么名字，就先叫炼金术师论坛算了）

最右边是用户的头像和昵称，鼠标悬浮时显示下拉列表，有“个人主页”，“管理员功能”，“退出登录”

## 主页

一个论坛主页的样子，有不同的版块，点进去后可以看到不同的帖子列表。

具体有哪些帖：从 `posts` 文件夹里面动态读取 `.json` 文件，把属于同一个板块里面的帖子的标题列在对应的地方

在某个不太显眼的地方要写：当前仅显示最近一周的帖子，想查看更久远的帖子请自己搜索关键词。以及 最近一周的活跃用户共有6人。
（活跃用户这个词有下划线，鼠标悬浮上去后显示 活跃用户指的是发过帖子或回复过帖子的用户 ）

## 搜索页

在主页的上方有一个搜索框，右边有一个按钮，点击后搜索；

玩家点击按钮后，跳转到搜索页面，最上方还是 nav ，然后下面是搜索框，再下面一点写着“与[用户刚刚搜的关键词]有关的帖子有：”

然后下面是有关的帖子的列表

## 管理员功能页

这个页面里面列出来一些功能，其他一些功能都是假的，点不了的，例如什么“发布新公告”之类的，点了以后弹窗提示说该功能暂时不可用。

只有一个功能是能用的，就是“查询用户”。
点击该按钮后跳转到查询用户界面。

有几个信息需要玩家去填：
1. 要查询的用户名（文本框）
2. 该用户的性别（单选，女、男、其他）
3. 该用户的家乡省份（单选，选项按照首字母顺序列出了我国所有省份或省级的区域）
4. 该用户的职业（单选，选项有很多很多职业）（注意：选项里面不应有“学生”！因为user2同时是学生和producer，防止冲突）

下面有一个提交按钮，如果输错了就提示说不对，如果输对了就解锁对应用户，取消其匿名状态。
在下方出现该用户的头像和昵称，点击后可跳转到ta的主页。

## 帖子页

就是普通的论坛帖子的样子……通过读 `posts` 里面的 `json` 文件来加载。

有一个楼主和帖子的主要内容，下面有很多人回复。

最下面还有一个假装的让用户回复这个帖子的文本框，但是它的“发表回复”的按钮是disable的，文本框里面的字提示说“管理员已暂时关闭本站的回复功能~”

## 用户的主页

能看到该用户的头像和昵称

还有个人信息（性别、家乡、职业等等）

还有一个按钮是“查看私信（仅管理员可用）”

## 用户的私信

通过 `texts/messages` 里面的 .json 文件加载。

管理员（萌萌小兔兔宝宝）自己的私信页面：基本上是空的

其他用户的私信页面：只有对话的双方都解除了匿名状态才能显示。

## 匿名的逻辑

帖子有两种，匿名贴和非匿名贴。

匿名贴的发帖人和回复的人，会被随机分配一种匿名名称，以及对应的头像。

在玩家解锁该用户的匿名状态后，在所有的帖子里面，该用户的头像和昵称变回其原本的头像和昵称。
